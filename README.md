# zhaisubao-cards

宅速報（IG @realestateman2026）每日字卡。

- `zhaisubao_card.py`：字卡產生器（1080x1080），用法 `python3 zhaisubao_card.py spec.json cards/YYYYMMDD.png`
- `chars/`：9 張角色圖（busy 忙碌 / nope 沒法度 / why 為什麼 / headache 傷腦筋 / thanks 辛苦了 / congrats 恭喜 / great 超爽的 / ok 了解 / finally 久等了）
- `cards/`：每日字卡，Metricool 透過 raw.githubusercontent.com 公開網址抓圖發 IG

此倉庫需維持 Public，IG 才抓得到圖。
